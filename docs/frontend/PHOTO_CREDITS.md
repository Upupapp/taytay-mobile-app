# Photo credits

The welcome scenes use the photographs from the design source. They are not
redrawn. Each credit is shown on the scene that uses the file.

| File | Scene | Credit |

The files are the design JPEGs (`src/1_municipal_hall.jpg`, `src/2_tiangge.jpg`,
`src/3_church.jpg`). SHA-256 is recorded in `lib/core/assets/asset_manifest.dart`.
They are not precached. The municipal seal is a separate file and is not a
photograph.

the sentence in `test/fixtures/mock/offices.json`. The hall inset reuses
